# Biblioteca 04 · Tarea 5

Sistema de biblioteca en línea con catálogo, préstamos y devoluciones, y tres roles: Administrador, Bibliotecario y Lector. Hecho para la tarea 5 de Programación Web Avanzada.

- Sitio: https://pwtarea5.infinityfreeapp.com
- Repositorio: https://github.com/jorgevillamar369-glitch/PWTAREA5

## Tecnologías

PHP 8, MySQL con PDO, HTML, CSS, Bootstrap 5 y JavaScript. La base de datos está en `sql/pwtarea5.sql` y la conexión en `includes/config.php`; las credenciales locales van en `includes/config.local.php`, que no se publica.
